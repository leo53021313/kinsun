## BearStage 取代 AvatarPlaceholder

**刪除** `components/AvatarPlaceholder.tsx`（`maxWidth: 285` 的橫式版本）。

**改法**：`talk.tsx` 的 import 與用法

```tsx
// 舊
import { AvatarPlaceholder, type AvatarState } from "@/components/AvatarPlaceholder";
<AvatarPlaceholder state={avatar} />

// 新
import { BearStage, type BearSystemState } from "@/components/BearStage";
<BearStage systemState={avatar} emotion={replyEmotion} />
```

`AvatarState` 型別改名 `BearSystemState`，但底層都是 `TalkVisualState`，狀態機完全不動。

**`replyEmotion` 是新的 state**：從後端回應裡取 LLM 挑的情緒。後端還沒回傳這個欄位前，傳 `null` 即可——`BearStage` 會 fallback 到系統態的圖。

## talk.tsx 要改的四處

### 1. 版面骨架改絕對定位

現在是 `ScrollView` 整頁可捲。改成固定不捲：

```
頁首（z4，top 66）→ 角色舞台（z1，top 140，固定）→ 內容層（z2，貼底往上長）→ 主鍵（z3，bottom 40）
```

**例外**：系統字級 ≥150% 時只有內容層變可捲，角色、頁首、主鍵仍固定。用 `useWindowDimensions` 的 `fontScale` 判斷。

### 2. 主鍵兩種尺寸

`speaking` 態時縮成 72dp、淡黃底 `#FDF6DE`、`#7A5E12` 圖示，改橫向排列，標籤換 `strings.talk.actions.waitWhileSpeaking`。其餘態維持 132dp 暖黃。

切換動畫 240ms ease-out，與回話卡的高度變化同一段（`motion.layout`）。

### 3. 回話卡展開與收合

**新增一個 `collapsed` 旗標**（不是新的 `TalkVisualState`，狀態機不動）：

- 阿白開始說話 → 卡片展開，主鍵縮 72
- 說完 → `collapsed = true`，卡片收成單行摘要膠囊（`strings.talk.collapsedPrefix` ＋ 回答前 12 字 ＋ `…`），主鍵長回 132
- 點膠囊 → `collapsed = false`，回全文

收合只動高度與圓角，位置不變、文字不淡出。

**⚠ 展開的時機接第一段抵達，不是整段合成完。** 現有的分段播放優化（伺服器只先合成第一句就送出）就是為了讓長輩不用等 5–8 秒，卡片若等整段會把這個優化吃掉。

### 4. 頁首左側加入口

原本只有右側鈴鐺。左側加一顆 60dp 圓鈕進「之前聊過的」，`strings.elderHistory.entryButton`。

## todayLog 的寫入點

一輪對話結束時（回答播完、`collapsed` 設為 true 的同一個地方）呼叫：

```ts
import { appendTurn } from "@/lib/todayLog";

await appendTurn({ at: Date.now(), said: transcript, reply: replyText, source: replySource });
```

登出時呼叫 `clearToday()`。
