## 檔案要怎麼搬

expo-router 是檔案路由，`guardian/_layout.tsx` 一放進去，`guardian/` 底下**所有**檔案都會變成 tab。所以深層頁面要先搬出來。

### 搬移

| 現在 | 搬到 | 為什麼 |
| --- | --- | --- |
| `guardian/elder/[elderId]/index.tsx` | `guardian-detail/elder/[elderId]/index.tsx` | 深層頁，不該有 tab bar |
| `guardian/elder/[elderId]/schedules.tsx` | `guardian-detail/elder/[elderId]/schedules.tsx` | 同上 |
| `guardian/login.tsx` | `auth/guardian-login.tsx` | 未登入時不該看到 tab bar |
| `guardian/register.tsx` | `auth/guardian-register.tsx` | 同上 |

### 留在 guardian/（會變成 tab）

`home.tsx`、`notifications.tsx`，加三支新的：`report.tsx`、`add.tsx`、`profile.tsx`。

`add.tsx` 不是真的分頁——中央黃鍵按下去要 `router.push` 到新增提醒流程。做一支只有 `useEffect` 導向的空畫面，或用 `listeners={{ tabPress: e => { e.preventDefault(); router.push(...) } }}`。**後者較好**，不會在返回堆疊留下空白頁。

## strings.ts 要補

批次 1 的 `strings.ts` **沒有** `guardianTabs`，這批要加：

```ts
guardianTabs: {
  home: "首頁",
  report: "報告",
  add: "新增提醒",
  addA11y: "新增用藥或回診提醒",
  notifications: "通知",
  profile: "阿公",        // TODO：應該用家屬設定的長輩稱呼，不是寫死
},
```

`profile` 那個 tab 的標籤在設計稿是長輩的稱呼（「阿公」）。寫死不對——多位長輩時會錯。**建議先寫死跑通，再改成讀當前選定的長輩。**

## 三個容易踩的坑

**1. 返回鍵行為。** Android 實體返回鍵在 tab 內按下時，預設會退出 App 而不是切回首頁 tab。要 `useFocusEffect` ＋ `BackHandler` 處理。

**2. 未讀數。** `tabBarBadge` 要由 `notifications.tsx` 自己 `navigation.setOptions` 設定，不要放在 layout——layout 拿不到 session。

**3. 深層頁的返回。** 從 tab 內 push 到 `guardian-detail/*` 後，返回要回到原本那個 tab。expo-router 預設會處理，但**如果用了 `router.replace` 就會斷**。全部用 `push`。
