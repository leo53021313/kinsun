## theme.ts 改了什麼

**移除** `talkColors`（整組）。引用它的檔案會編譯失敗——這是刻意的，順著錯誤清單改比自己找漏網的可靠。已知會壞的是 `app/elder/talk.tsx`。

**新增**
- `colors` 全部換新值，多了 `action`／`actionPressed`／`dangerText`／`dangerBadge`／`warning`
- `elderGradient` — 長輩端暖光漸層，RN 要搭 `expo-linear-gradient`
- `talkState` — 五個系統態的光暈與狀態帶色，沿用既有 `TalkVisualState` 名稱
- `emotionPolicy` — 兩層情緒的規則與黑名單
- `avatar` — 角色插槽尺寸
- `radius`／`elevation`／`motion` — 原本散在各檔的值收攏

**注意** `elevation` 的值是 CSS 字串，RN 要轉成 `shadowOffset`／`shadowRadius`／`elevation`。轉換時保持視覺一致即可，不必逐值對應。

## strings.ts 改了什麼

### 人稱規則

| | 用什麼 | 例 |
| --- | --- | --- |
| 阿白自述 | 第一人稱「我」 | `talk.listening: "我在聽…"` |
| 系統描述角色 | 第三人稱「阿白」 | `talk.status.speaking: "阿白正在說話"` |
| 服務主體 | 「金孫」不改 | `guardianHome.consent`、`role.brand` |
| 家屬端 | 一律第三人稱 | `dailySummary.noticedSection: "阿白注意到的"` |

**不能用全域取代。** `bindFailed: "連不上金孫"`、`loginLink: "用過金孫？"`、`role.brand` 與整段 `consent` 都是服務名，要留。

### 新增的 key

- `talk.statusSub` — 五個狀態的副標，阿白自述
- `talk.actions.waitWhileSpeaking` / `replay` — 主鍵 72dp 次要態
- `talk.collapsedPrefix` / `sourceHealthEdu` / `errorStep1-2` / `errorReassure` / `errorRetry`
- `elderHistory.*` — 批次 4 的當天對話畫面
- `guardianHome.todaySection` 等 — TodayCard
- `dailySummary.*` / `criticalAlert.*` — 批次 6 的新畫面
- `schedules.step*` 等 — 兩步流程
- `elderNotifications` 多了單題確認畫面的文案
