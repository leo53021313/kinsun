# 內測基礎建設 批① 總開關＋meta 端點＋.env 整理 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立後端單一內測總開關 `INTERNAL_TESTING_ENABLED`，經公開 `GET /api/v1/meta` 下發給 App 與觀測後台，並把內測旗標集中整理到 `.env.example` 的「內部測試」區塊。

**Architecture:** 開關為 `Settings` 一欄（預設 `false`）；meta 端點是無認證的唯讀路由工廠（`create_meta_router`），只回一個布林，掛在 `/api/v1` 前綴下。前端共用型別加 `Meta`。

**Tech Stack:** Python 3.12＋FastAPI＋pytest；TypeScript（shared 型別）。

**依據 spec：** `docs/superpowers/specs/2026-07-12-內部測試基礎建設-design.md` §3.1

## Global Constraints

- 台灣繁體中文註解與 commit 訊息；全形標點。
- 環境變數鍵＝Settings 欄位名大寫，100% 一一對應（AGENTS.md）。

- [ ] **Step 3: 實作**——新檔 `src/kinsun/web/routers/meta.py`：

```python
"""公開 meta 端點（spec 2026-07-12 §3.1）：向前端下發伺服器模式，不含機敏值。

App 與觀測後台啟動時查一次；只回布林旗標，故不需認證。
取不到時前端一律當 false（fail-safe，正式行為不受影響）。
"""

from __future__ import annotations

from fastapi import APIRouter

from kinsun.web.envelope import ok


def create_meta_router(*, internal_testing_enabled: bool) -> APIRouter:
    router = APIRouter(tags=["meta"])

    @router.get("/meta")
    def meta() -> dict:
        return ok({"internal_testing": internal_testing_enabled})

    return router
```

`routers/__init__.py`：`from kinsun.web.routers.meta import create_meta_router` 加入匯入區，
`__all__` 加 `"create_meta_router"`。

`app.py`：`from kinsun.web.routers import (...)` 加 `create_meta_router`；
在 app_turns router 掛載之後加：

```python

    app.include_router(
        create_meta_router(internal_testing_enabled=settings.internal_testing_enabled),
        prefix="/api/v1",
    )
```

`shared/types.ts` 檔尾加：

```ts

export type Meta = { internal_testing: boolean };
```
