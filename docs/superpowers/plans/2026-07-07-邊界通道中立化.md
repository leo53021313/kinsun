# 邊界通道中立化（階段 1C）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 通道識別徹底退到邊界——入站 `InboundMessage` 改帶 `(channel, external_id)`、出站以 `ChannelRouter` 依綁定路由、帳號讀取端切到 `channel_bindings`。完成後新增 App 通道不需再碰身分層。

**Architecture:** 三個切面各自獨立可交付：（1）帳號讀取端 `get_elder_by_line`／`get_guardian_by_line` 內部改查 `channel_bindings`（外部行為不變）；（2）入站：`InboundMessage.line_user_id` 改為 `channel`＋`external_id`，閘門解析改 `(channel, external_id)`；（3）出站：新增 `channels/router.py` 的 `ChannelRouter`（本人 → 綁定通道 fan-out），危急通知、主動關懷、用藥／回診提醒全部改吃「本人識別」。`elders.line_user_id`／`guardians.line_user_id` 欄位與雙寫**本計畫不動**（收縮步留給 1D）；觀測五表補 `elder_id` **刻意延後**（等管理端有查詢需求時一併做，於設計文件註記）。

**Tech Stack:** 同 1A／1B。

## Global Constraints

- 同 1A／1B 計畫（繁中全形標點、命名規範、每 Task 全綠才 commit、不加套件）。
- 設計源頭：`docs/superpowers/specs/2026-07-07-app通道與身分中立化-design.md` §4.1(3)。

- 家屬 LINE 文字選單（`medications/flow.py`、`appointments/flow.py`）與綁定引導流程（`binding/`）為通道專屬對話，不動。

**Interfaces（Produces）:** 簽名不變；實作改為兩段查詢——`get_channel_binding(Channel.LINE, line_user_id)` → 檢查 `principal_type` → `get_elder`／`get_guardian`。Pg 與 Fake 共用同一邏輯形狀：

```python
    def get_elder_by_line(self, line_user_id: str) -> Elder | None:
        binding = self.get_channel_binding(Channel.LINE, line_user_id)
        if binding is None or binding.principal_type is not PrincipalType.ELDER:
            return None
        return self.get_elder(binding.principal_id)
```

（guardian 版同形，`PrincipalType.GUARDIAN`＋`get_guardian`。）

**Interfaces（Produces）:**

```python
# channels/router.py
class BindingDirectory(Protocol):
    def list_channel_bindings_for_principal(
        self, principal_type: PrincipalType, principal_id: str
    ) -> list[ChannelBinding]: ...

class ChannelRouter:
    """本人 → 綁定通道的出站路由：對每個已綁定且有 adapter 的通道各送一次。
    單一通道失敗只記錄、不中斷其他通道。"""

    def __init__(
        self, directory: BindingDirectory, channels: Mapping[Channel, OutboundChannel]
    ) -> None: ...
    def has_route(self, principal_type: PrincipalType, principal_id: str) -> bool: ...
    def send_text(
        self, principal_type: PrincipalType, principal_id: str, text: str
    ) -> int: ...  # 回傳成功送出的通道數

# channels/outbound.py（僅參數改名，語意不變）
class OutboundChannel(Protocol):
    def send_text(self, external_id: str, text: str) -> None: ...

# safety/notifier.py
class GuardianDirectory(Protocol):
    def guardians_of(self, elder_id: str) -> list[ElderGuardian]: ...

class GuardianNotifier:  # 更名自 LineGuardianNotifier（已通道中立）
    def __init__(self, directory: GuardianDirectory, router: ChannelRouter) -> None: ...
    def notify(self, elder_id: str, assessment: RiskAssessment) -> None: ...
```

- worker `_push_to_elder`：先 `router.has_route(ELDER, elder_id)` 再生成內容（避免白花 LLM）；送出改 `router.send_text`。
- composition：`account_store = PgAccountStore(db)` 抽出共用；`Core.channel` 改為 `Core.router = ChannelRouter(account_store, {Channel.LINE: LineOutboundChannel(externals.messenger)})`（`channel` 欄位若無其他使用端即移除）。
- app.py：`notifier=GuardianNotifier(core.accounts, core.router)`。
