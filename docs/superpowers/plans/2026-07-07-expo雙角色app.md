# Expo 雙角色 App（階段 4）實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `app/` 單一 Expo 專案（React Native＋TypeScript）：家屬帳密登入進管理介面（長輩、用藥、回診、健康報告、邀請碼），長輩綁定碼登入進對講機介面（整頁大按鈕、按著說話、自動播放回覆、虛擬形象預留區）。Expo Go 掃 QR 實機預覽。

**Architecture:** `create-expo-app` 官方模板（含 expo-router 檔案式導航）起骨架後清空範例；`lib/api.ts` 統一 fetch（`EXPO_PUBLIC_API_URL`、Bearer token、snake_case 型別與後端一致）、`lib/auth.ts` 以 expo-secure-store 持久化 `{role, token}`；入口 `index` 依儲存的角色自動導向。長輩端用 expo-audio：押住錄音（m4a）→ raw body POST `/api/app/turns` → 回覆文字放大顯示＋自動播放 `audio_url`。

**Tech Stack:** Expo SDK（最新）、expo-router、expo-secure-store、expo-audio；皆可在 Expo Go 執行（開發期無推播，符合規劃）。

## Global Constraints

- 設計源頭：spec §4.4。前端註解／文案繁中；JSON 欄位 snake_case 與後端一致。
- 長輩介面適老化：最小字級 22、主按鈕佔半屏、高對比、無多層導航（綁定後直達對講機）。
- 虛擬形象預留：對講機畫面中央 `AvatarPlaceholder` 元件（靜態表情＋說話狀態樣式切換），日後換 Rive／Live2D 不動版面。
- RN 紀律（community-react-native）：Pressable、StyleSheet.create、文字一律包 `<Text>`、不用 falsy `&&` 條件渲染。
- 驗證下限：`npx tsc --noEmit` 全綠＋`npx expo-doctor` 通過；實機體驗由 Leo 以 Expo Go 驗收（我無手機）。
