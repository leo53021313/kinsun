| DDD 元素 | 程式碼位置 | 說明 |

```mermaid
    participant TTS as TTS 服務
    participant DB as Postgres
    participant LINE as LINE（家屬通道）

    Elder->>App: 按住說話→放開
    App->>API: POST /api/app/turns（Bearer＋音檔）
    API->>API: 認證＋同意複核（403 若撤回）
    API->>ASR: POST /transcribe（raw bytes）
```


### 4.2 一致性策略

- **強一致**：單一 Postgres 內全部交易（帳號、同意、提醒、危急事件）。
- **最終一致**：Mem0 長期記憶——夜間 3:00 整批 consolidation（前一天對話→事實），白天檢索到的是「昨天以前」的長期記憶＋當日短期記憶。
- **刻意不一致**：LINE 事件單筆失敗吞掉不重送（`webhook.py:53-56`）——寧漏一則、不重複危急通知。
