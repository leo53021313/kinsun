| 維度 | 目標 | 備註 |

| 可靠性 | App 錯誤在地化對照表為基準，web 端向其看齊（D-46 字典） | |

## 2. 系統化分層（as-is → to-be）

| 層級 | App（Expo） | LIFF／admin | to-be 變更 |
| :--- | :--- | :--- | :--- |
| 感知層 | RN＋StyleSheet＋theme.ts token | React 18；LIFF 無樣式、admin 自帶 css | LIFF 維持極簡，App 定稿後跟進（✅ D-53） |
| 互動層 | 手寫受控表單（頁面少） | 同 | 維持，不引入表單庫 |
| 狀態層 | **無全域 store**（每頁 loadSession） | 無 | **App 加 AuthProvider 集中 session（✅ D-45）**；不引入 Redux/Zustand |
| 通訊層 | `lib/api.ts` 統一 `request<T>`＋ApiError(status, detail) | 各自 api.ts（僅 status） | 共用包統一 ApiError＋信封解包（D-23／D-51） |
| 基礎設施 | Expo 57＋expo-router＋typedRoutes＋reactCompiler | Vite 6 雙 config（/liff、/admin 分 build） | 前端測試框架缺席——列 16_WBS 評估（現僅 tsc＋expo-doctor） |

## 3. 設計系統

- **Design tokens**（`app/src/lib/theme.ts`）：暖磚橘 primary `#C2410C`、背景 `#FFF9F0`、9 色；elder 字級 22/30/40；spacing 4/8/16/24/40。此為三端視覺基準（LIFF 跟進時沿用，D-53）。
- **元件層**：Atoms＝`ui.tsx`（Button／Field／ErrorText／Section／EmptyHint，均帶 accessibilityRole）；Organisms＝AvatarPlaceholder（180×180 固定框，內部可換 Rive／Live2D 不動版面）。
- **樣式紀律**：一律 `StyleSheet.create`，不用 inline object／CSS-in-JS。

## 4. 效能策略

- App：對講機鏈路（錄音→上傳→回覆→播放）為唯一關鍵路徑；音檔上限 env 化（D-26）；錄音採 expo-audio HIGH_QUALITY。
- web 端：內部工具，不做 code splitting 投資；admin 輪詢 5s＋隱藏暫停＋回前景補跑（✅ D-47 維持）。

## 5. 技術可用性

- **無障礙（長輩端，✅ D-48）**：系統字級跟隨（管理 allowFontScaling）＋最小點擊區 48pt＋錄音觸覺（haptics）與音效回饋；對比維持亮色高對比（D-49）。
- **i18n**：不導入框架（✅ D-50）；字串集中常數檔，`zh-TW` 單語系；台語為語音層（ASR/TTS）非文字層。

## 6. 工程化實踐

- 檔案組織：`app/src/{app,components,lib}`（expo-router 檔案即路由）；`frontend/src`＋`frontend/src/admin`（雙 Vite config 分 build：`dist/`、`dist-admin/`）。
- 型別：TypeScript；App 有 typedRoutes；React 版本落差（App 19／web 18）——記錄現況，收斂於 LINE 退場時。
- to-be 共用包（✅ D-51）：型別（Elder/Medication/…）＋用語字典（tier/slot/錯誤，值待 D-46 會議）＋時間格式化（epoch 秒→zh-TW），三端引用。

## 7. 前後端協作

- 統一經 API client 封裝（三端皆已做）；JSON snake_case 與後端同鍵名（AGENTS.md）。
- **信封＋v1 遷移**（D-23／D-27）：三端解包點與路徑一次改（工項 API-1），共用包同批建立。
- Token：App 存 SecureStore（✅ 敏感資料不進 localStorage——admin 金鑰存 localStorage 為內部工具例外，13 循環複核）；家屬 token 效期＋登出（D-25）落地時 App 需處理 `token_expired` 重新登入流。
- admin 401 自動回輸入頁（✅ D-52）。

## 8. 監控與安全

- 前端監控：無（內部展示規模，不裝 Sentry）；錯誤呈現以 replyText／ErrorText 在地化。
- 安全檢查（13 循環彙整）：XSS 靠框架跳脫；無 CDN 外部資源；admin key localStorage 例外已知。
