## 3. 設計系統

- **Design tokens**（`app/src/lib/theme.ts`）：暖磚橘 primary `#C2410C`、背景 `#FFF9F0`、9 色；elder 字級 22/30/40；spacing 4/8/16/24/40。此為三端視覺基準（LIFF 跟進時沿用，D-53）。
- **元件層**：Atoms＝`ui.tsx`（Button／Field／ErrorText／Section／EmptyHint，均帶 accessibilityRole）；Organisms＝AvatarPlaceholder（180×180 固定框，內部可換 Rive／Live2D 不動版面）。日期輸入用系統原生選擇器（`@react-native-community/datetimepicker` 8.4.4，✅ 2026-07-12 Leo 核准——App 唯一 UI 第三方元件，Expo Go 內建支援）；用藥時段為自製多選 chips（`Pressable`＋`accessibilityRole="checkbox"`）。
- **樣式紀律**：一律 `StyleSheet.create`，不用 inline object／CSS-in-JS。

## 4. 效能策略

- App：對講機鏈路（錄音→上傳→回覆→播放）為唯一關鍵路徑；音檔上限 env 化（D-26）；錄音採 expo-audio HIGH_QUALITY。
- web 端：內部工具，不做 code splitting 投資；admin 輪詢 5s＋隱藏暫停＋回前景補跑（✅ D-47 維持）。

## 5. 技術可用性

- **無障礙（長輩端，✅ D-48）**：系統字級跟隨（管理 allowFontScaling）＋最小點擊區 48pt＋錄音觸覺（haptics）與音效回饋；對比維持亮色高對比（D-49）。
- **i18n**：不導入框架（✅ D-50）；字串集中常數檔，`zh-TW` 單語系；台語為語音層（ASR/TTS）非文字層。

## 6. 工程化實踐

- 檔案組織：`app/src/{app,components,lib}`（expo-router 檔案即路由）；`frontend/src`＋`frontend/src/admin`（雙 Vite config 分 build：`dist/`、`dist-admin/`）；JS 測試與被測檔同目錄（co-located `*.test.ts(x)`）。
- 型別：TypeScript；App 有 typedRoutes；React 版本落差（App 19／web 18）——記錄現況，收斂於 LINE 退場時。
- 共用包（✅ D-51 已落地）：型別（Elder/Medication/…）＋用語字典（terms）＋時間格式化＋信封＋`createApiClient`（`shared/` 六檔），三端引用；字串常數三端各自 `strings.ts` 集中（✅ D-50，庚-31）。
- 載入模式（2026-07-17）：admin 統一用 `useLoadable<T, E>(fetcher, mapError?)`（`frontend/src/admin/useLoadable.ts`，回 `{data, error, reload}`；fetcher 回 null＝本輪不載入；錯誤留到成功才清），七頁（MemoryTab／RiskNotificationsTab／RemindersTab／ElderTimelinePage／SystemPage／TraceDetailPage／AccountTab）共用，消除 effect 內同步 setState；`usePolling` 的 ref 更新改於 useEffect 內（並發渲染安全）。

## 7. 前後端協作

- 統一經 API client 封裝（三端皆已做，但 wrapper 各寫一份——F-12）；JSON snake_case 與後端同鍵名（AGENTS.md，2026-07-10 實證 `shared/types.ts` 全欄位合規、三端直讀不轉 camelCase）。
- **信封＋v1 遷移**（D-23／D-27）：三端解包點與路徑一次改（工項 API-1），共用包同批建立。
- Token：App 存 SecureStore（✅ 敏感資料不進 localStorage——admin 金鑰存 localStorage 為內部工具例外，13 循環複核）；家屬 token 效期＋登出（D-25）落地時 App 需處理 `token_expired` 重新登入流。
- admin 401 自動回輸入頁（✅ D-52）。
- 內測功能顯示（✅ D-73，2026-07-12）：伺服器 `INTERNAL_TESTING_ENABLED` 經公開 `GET /api/v1/meta` 下發（`kinsun-shared` `Meta` 型別三端共用）；App「切換身分」（RoleSwitcher）與 admin 手動觸發按鈕依此顯示，meta 取不到一律當 false（fail-safe，正式行為不變）。App session 儲存為雙 slot（`kinsun_session_guardian`／`kinsun_session_elder`＋目前身分指標，舊 key 自動搬遷）。

## 8. 監控與安全

- 前端監控：無（內部展示規模，不裝 Sentry）；錯誤呈現以 replyText／ErrorText 在地化。
- 安全檢查（13 循環彙整）：XSS 靠框架跳脫；無 CDN 外部資源；admin key localStorage 例外已知。
- 位置隱私（2026-07-17）：對講機附帶的定位在裝置端就模糊化（`lib/location.ts` 四捨五入至 0.01 度，約 1.1 公里），精確座標不離開手機；取不到定位一律靜默降級（不阻擋對話）。
