⚠️ **`web/` 狀態層與 App 最根本的差異**（P1 地基，2026-07-30）：App 的 `SessionProvider` 是掛根節點的**單例**，一個分頁只有一份登入狀態；`web/` 的雙欄舞台要**左右兩欄同時各自登入**，這個形狀行不通，故改為工廠——`createSessionContext(role)` 每次呼叫產生一組獨立的 Provider／hook，持久化 key 分開（`kinsun_web_session_elder`／`kinsun_web_session_guardian`），互不干擾（`web/src/session/createSessionContext.tsx`）。持久化改用 `localStorage`：App 用的 `expo-secure-store` 在瀏覽器是空實作（`ExpoSecureStore.web.ts` 內容為 `export default {}`），沒有可搬的路；風險比照既有「admin 金鑰存 localStorage」例外同級（見 §8）——本前端只服務內部測試帳號。
⚠️ **`signIn` 收 `Omit<Session, "role">`**（P1 全分支審查 I3）：角色由工廠決定，呼叫端傳不進來。原本 `signIn` 收整個 `Session`，寫入用呼叫端的 `next.role`、讀取與清除卻用工廠的 `role`——在長輩 context 上傳成 `guardian`，畫面顯示長輩已登入、token 卻落在家屬鍵、長輩鍵是 null，重整之後兩欄對調。那是「兩欄互不干擾」唯一可被違反的路徑，而且看起來像永久故障，故從簽章拿掉讓它連傳錯都不可能（內部 `saveSession({ ...next, role })`，role 放展開之後）。

## 3. 設計系統

- **Design tokens**（`app/src/lib/theme.ts`）：暖磚橘 primary `#C2410C`、背景 `#FFF9F0`、9 色；elder 字級 22/30/40；spacing 4/8/16/24/40。此為四端視覺基準（LIFF 跟進時沿用，D-53；`web/` 2026-07-30 起以 `theme.css` 的 Tailwind v4 `@theme` 沿用同一組色值與字級，命名因 Tailwind 內建工具類撞名而略有出入：`text`／`textSoft`／`border` 改為 `ink`／`ink-soft`／`line`）。
- **元件層**：Atoms＝`ui.tsx`（Button／Field／ErrorText／Section／EmptyHint，均帶 accessibilityRole）；Organisms＝AvatarPlaceholder（180×180 固定框，內部可換 Rive／Live2D 不動版面）。日期輸入用系統原生選擇器（`@react-native-community/datetimepicker` 8.4.4，✅ 2026-07-12 Leo 核准——App 唯一 UI 第三方元件，Expo Go 內建支援）；用藥時段為自製多選 chips（`Pressable`＋`accessibilityRole="checkbox"`）。
- **樣式紀律**：一律 `StyleSheet.create`，不用 inline object／CSS-in-JS。

## 4. 效能策略

- App：對講機鏈路（錄音→上傳→回覆→播放）為唯一關鍵路徑；音檔上限 env 化（D-26）；錄音採 expo-audio HIGH_QUALITY。
- 回覆音檔隨 WS binary 訊框直送（2026-07-30 延遲優化 C1）：`lib/replyAudio.ts` 把位元組寫成`Paths.cache/kinsun-reply/*.m4a` 再交給播放器，省掉「後端上傳 Supabase→App 再下載」兩趟網路。三個實作約束：①`expo-audio` 的 `AudioSource` **只吃 uri**，沒有吃記憶體位元組的路（iOS 雖認得 `data:audio/…`，但它內部就是寫進拿不到檔名、永不清理的暫存目錄，副檔名還靠 MIME 猜）；②副檔名**必須**是 `.m4a`，AVPlayer 推不出型別就載不起來；③`expo-file-system` v54 的舊 API（`writeAsStringAsync` 等）**執行期會拋**，只能用 class-based 的 `File`／`Directory`／`Paths`，而 `File.write` 吃 `Uint8Array`、是同步呼叫（回傳即已落盤，故 write→replace→play 無競態）。
  檔案自己收：cache 只在裝置儲存吃緊時才被系統回收。策略＝進畫面整個子目錄清掉重建＋環狀保留最新 3 個。⚠️ 刻意**不做「播完就刪」**——`playAndWait` 的保險逾時可能在播放器還在讀檔時就放行，留 3 個保證「正在播的那一個」永遠不在刪除範圍內。
  ⚠️ `lib/talkSocket.ts` **不可** import `expo-file-system`：它的離線可測性（`talkSocket.test.ts`不 import 任何 expo 模組）是刻意的設計，故寫檔以注入點 `writeAudio` 由 `talk.tsx` 提供，socket 只負責協定解析。落地失敗仍把訊框交出去（`audio_url` 留空）——字幕與分段資訊照樣有用。
- web 端：內部工具，不做 code splitting 投資；admin 輪詢 5s＋隱藏暫停＋回前景補跑（✅ D-47 維持）。

## 5. 技術可用性

- **無障礙（長輩端，✅ D-48）**：系統字級跟隨（管理 allowFontScaling）＋最小點擊區 48pt＋錄音觸覺（haptics）與音效回饋；對比維持亮色高對比（D-49）。
- **i18n**：不導入框架（✅ D-50）；字串集中常數檔，`zh-TW` 單語系；台語為語音層（ASR/TTS）非文字層。

## 6. 工程化實踐

- 檔案組織：`app/src/{app,components,lib}`（expo-router 檔案即路由）；`frontend/src`＋`frontend/src/admin`（雙 Vite config 分 build：`dist/`、`dist-admin/`）；JS 測試與被測檔同目錄（co-located `*.test.ts(x)`）。
- 型別：TypeScript；App 有 typedRoutes；React 版本已大致收斂（App 19.1／web 19.2.8——2026-07-25 audit 修復升級：react-router 8.3 要求 React ≥ 19.2.7，web 端自 18.3 升 19；路由 import 自 `react-router-dom` 改 `react-router`）。
- 共用包（✅ D-51 已落地）：型別（Elder/Medication/…）＋用語字典（terms）＋時間格式化＋信封＋`createApiClient`（`shared/` 六檔），三端引用；字串常數三端各自 `strings.ts` 集中（✅ D-50，庚-31）。
- 載入模式（2026-07-17）：admin 統一用 `useLoadable<T, E>(fetcher, mapError?)`（`frontend/src/admin/useLoadable.ts`，回 `{data, error, reload}`；fetcher 回 null＝本輪不載入；錯誤留到成功才清），八頁（MemoryTab／RiskNotificationsTab／RemindersTab／ElderTimelinePage／SystemPage／TraceDetailPage／AccountTab／NewsPage，2026-07-25 增話題新聞頁）共用，消除 effect 內同步 setState；`usePolling` 的 ref 更新改於 useEffect 內（並發渲染安全）。

## 7. 前後端協作

- 統一經 API client 封裝（三端皆已做，但 wrapper 各寫一份——F-12）；JSON snake_case 與後端同鍵名（AGENTS.md，2026-07-10 實證 `shared/types.ts` 全欄位合規、三端直讀不轉 camelCase）。
- **信封＋v1 遷移**（D-23／D-27）：三端解包點與路徑一次改（工項 API-1），共用包同批建立。
- Token：App 存 SecureStore（✅ 敏感資料不進 localStorage——admin 金鑰存 localStorage 為內部工具例外，13 循環複核）；家屬 token 效期＋登出（D-25）落地時 App 需處理 `token_expired` 重新登入流。
- admin 401 自動回輸入頁（✅ D-52）。
- 內測功能顯示（✅ D-73，2026-07-12）：伺服器 `INTERNAL_TESTING_ENABLED` 經公開 `GET /api/v1/meta` 下發（`kinsun-shared` `Meta` 型別三端共用）；App「切換身分」（RoleSwitcher）與 admin 手動觸發按鈕依此顯示，meta 取不到一律當 false（fail-safe，正式行為不變）。App session 儲存為雙 slot（`kinsun_session_guardian`／`kinsun_session_elder`＋目前身分指標，舊 key 自動搬遷）。

## 8. 監控與安全

- 前端監控：無（內部展示規模，不裝 Sentry）；錯誤呈現以 replyText／ErrorText 在地化。
- 安全檢查（13 循環彙整）：XSS 靠框架跳脫；無 CDN 外部資源；admin key localStorage 例外已知（`web/` 的雙 session token 存 localStorage 為同級例外，見 §2）。
- CSP（`web/security.py`，D-57 丙-9）2026-07-30 為 `web/` 再放寬兩處：`media-src` 加 `blob:`（WS 直送的回覆語音在瀏覽器只能落成 blob URL 再交給播放器）、`script-src` 加 `'wasm-unsafe-eval'`（長輩端掃 QR 用 `zxing-wasm` 需編譯 WebAssembly，Chrome 系瀏覽器以 `script-src` 管制）。
- 位置隱私（2026-07-17）：對講機附帶的定位在裝置端就模糊化（`lib/location.ts` 四捨五入至 0.01 度，約 1.1 公里），精確座標不離開手機；取不到定位一律靜默降級（不阻擋對話）。
