# ADR-008: 前端技術組合——React＋Vite（web）與 Expo（App）

> **狀態:** 已接受 | **日期:** 2026-07-08 | **決策者:** Leo（批次重新確認；App 部分＝D-08，2026-07-07 拍板）

## 1. 背景與問題

- **上下文**: 三個前端面：家屬 LIFF 儀表板（LINE 內嵌網頁）、開發觀測後台（admin）、雙角色 App。
- **驅動因素/約束**: 團隊無 Mac、無付費 Apple 帳號——Expo Go 是唯一能在實體 iPhone 預覽的路徑。

## 2. 考量的選項

- **現況組合**：LIFF／admin＝React＋Vite（build 產物由後端 StaticFiles 託管）；App＝React Native＋Expo（TypeScript、expo-router）。
- **統一全 Web**（PWA）：iOS 推播與麥克風權限受限，對講機體驗差。
- **原生雙平台**：7 人非本科團隊不可行。

## 3. 決策

**選擇**: 維持現況組合。LIFF 隨 LINE 通道凍結（只維運不加功能）；App 為主線。

**理由**: React 技能三面共用；Expo Go 解決無 Mac 的 iOS 預覽；D-08 已確認五項組合維持。

## 4. 後果

- **正面**: 單一技能棧；App 已通過 tsc＋expo-doctor 全綠。
- **負面**: 三個前端面短期並存，維護面較寬（LINE 退場後收斂）。
- **重新評估觸發**: LINE 通道正式退場時（LIFF 一併退役）。
