## A. 核心安全原則現況

- [x] 攻擊面：admin 未設金鑰即 fail-closed 503；正式環境強制 ConsentGate（D-19）
- [x] 內測操作面雙重守門（D-73，2026-07-12）：admin 手動觸發（jobs run／reminders dispatch）需 `X-Admin-Key`＋`INTERNAL_TESTING_ENABLED=true`（預設 false，關閉回 403 `internal_testing_disabled`）；公開 `GET /api/v1/meta` 僅回一個布林、無機敏值
- [ ] 最小權限：admin 單一共用金鑰可讀全部（✅ D-59 維持＋文案揭露）；DGX 零認證（✅ D-56 補）

## B. 資料安全與隱私

| 檢查 | 現況 | 處置 |
| :--- | :--- | :--- |
| PII 分類與同意 | 對話／音檔／危急事件＝健康敏感 PII；同意文案未提資料去向與保留 | 文案改版（D-14／D-15／D-59 揭露＝己-2）；✅ D-62 不做 re-consent，新版默認生效（會-3） |
| 傳輸安全 | 對外經 ngrok HTTPS；DGX 內網 HTTP | 可接受（校內網），DGX 金鑰補防（D-56） |
| 儲存安全 | Supabase 靜態加密託管；音檔私有 bucket＋短效簽章 URL ✅（2026-07-09 完成，甲-2） | 簽章效期 env 可調（預設 1 天） |
| 保留與銷毀 | 音檔 2 天自動清（0＝停用開關保留）／觀測 14 天自動清／對話永久（✅ D-14 文案明示） | mem0 本機 history.db 落點 → 14 循環 |
| 日誌脫敏 | ✅ 抽查通過：不印對話原文／token／密碼 | 列入 11 審查清單持續把關 |

## C. 應用程式安全

| 檢查 | 現況 | 處置 |
| :--- | :--- | :--- |
| 密碼雜湊 | scrypt N=16384,r=8,p=1、constant-time 比對 ✅ | 維持 |
| Token | SHA-256 存放 ✅；**無登出 ❌** | ✅ D-25 修訂（隨 D-71）：全 token 永久有效（不設效期）＋登出／作廢端點可主動撤銷 |
| 暴力破解 | 登入／註冊／裝置綁定 per-IP 節流 ✅（2026-07-09 完成，甲-3；10 次／5 分鐘 env 可調） | ✅ D-71 長輩登入（POST /elder-sessions）已沿用同節流（己-6，2026-07-10） |
| 帳號枚舉 | 註冊 email_taken 洩漏；登入 timing 差 | ✅ D-60 只修 timing（假雜湊），註冊維持 |
| 物件級授權 | 家屬操作先 `assert_manages` ✅ | 維持 |
| 注入 | SQL 全參數化 ✅（三處 f-string 皆白名單） | 維持 |
| XSS／headers | **安全標頭全缺 ❌**＋admin 金鑰存 localStorage | ✅ D-57 headers middleware；金鑰位置維持（內部工具＋CSP 補防） |
| 輸入驗證 | email 不驗格式；turns 不驗 content-type | ✅ D-61 都補 |
| 錯誤洩漏 | `admin api disabled` 503 洩組態 | 併 D-24 錯誤碼標準化改中性訊息 |
| 驗簽 | LINE webhook（SDK constant-time）✅；LIFF verify 帶 client_id ✅ | 維持 |

## D. 基礎設施安全

- [x] Secrets：無金鑰入庫、.env 未追蹤、.example 無真值 ✅
- [x] lock 檔：uv.lock＋兩個 package-lock ✅；**DGX requirements 未鎖 ❌** → ✅ D-56
- [ ] 依賴掃描：無自動化——CI（A-6）落地時加 `pip audit`／`npm audit`
