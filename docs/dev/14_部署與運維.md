## 1. 執行單元與啟停

`scripts/kinsun.sh` 統一管理六服務：`asr(8001) tts(8002) webhook(8000) scheduler frontend(5173) ngrok`——setsid 獨立進程組、log 至 `logs/<name>.log`、PID 至 `.run/<name>.pid`。

| 指令 | 行為 |
| :--- | :--- |
| `scripts/kinsun.sh start|stop|restart [服務]` | 全部或指定服務 |
| `scripts/kinsun.sh status` | PID 存活檢查 |

to-be：API 改多 worker 啟動（✅ D-20）。

## 3. 備份與資料保全（✅ D-63 修訂：輕量手動版，2026-07-09 已上線）

- **現況 ✅**：`scripts/backup_db.sh` 一鍵手動備份——以 Docker `postgres:17-alpine` 執行 pg_dump（DGX 未裝且伺服器為 PG 17），自訂格式存 `data/backups/`（gitignore 排除、檔案權限 600），完成後自動以 `pg_restore --list` 驗證可讀。
- **時機約定（不做排程——D-63 修訂）**：①資料庫結構大改前（如乙批 migration）②長輩實測開始前。還原指令見腳本檔頭註解。
- 2026-07-09 首次備份實測通過（328K／480 物件）。
- mem0 稽核檔：`history_db_path` 設至 `data/mem0/history.db`＋.gitignore（✅ D-65）。
- 音檔：**先不清理**（2026-07-09 修訂，`AUDIO_RETENTION_DAYS=0`；設 >0 可重新啟用過期清理）——Supabase 免費層 Storage 1GB，用量需留意。
