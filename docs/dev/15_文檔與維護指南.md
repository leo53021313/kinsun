## 3. 決議回填流程（明日會後第一件事）

1. 逐項把會議結論填入 00_決策清單「決議」欄（拍板人＋日期）。
2. 全庫搜 `⚠` 與該 D-xx 編號，改寫對應文件段落（PRD／BDD／05／07／12／17）。
3. 產生的新工項補進 16_WBS。
4. 更新 README 狀態表（🟡 待議中 → ✅ 定稿）。
5. 一個決議一個 docs commit（可合併同主題）。

## 4. 撰寫規範

- 台灣繁體中文＋全形標點（AGENTS.md）；主動語態、直接切入。
- as-is 陳述必附 `file:line` 證據；to-be 必附 D-xx 依據——**無出處的斷言視為未驗證**。
- 版頭固定：版本／日期／狀態（草稿🟡待議✅定稿）；文末變更紀錄表。
- 圖用 Mermaid（可 diff、可審查），不用外部繪圖檔（既有 drawio 為歷史資產）。
