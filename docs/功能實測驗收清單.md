## 1. 環境啟動 Runbook（Leo 或整合負責人先做）

### 1.1 webhook app（對話主流程，:8000）
```bash
cd /home/leo29/kinsun
uv run uvicorn --app-dir src "kinsun.app:build_app" --factory --port 8000
# 看到 "Application startup complete." 即成功
# 停止：pkill -f 'kinsun.app:build_app'
```

### 1.2 TTS 服務（CosyVoice 3，:8002；需在 DGX 的 cosyvoice 環境）
```bash
cd /home/leo29/kinsun
export TTS_MODEL_ID=/home/leo29/taigi-voice-agent/models/TTS/original/Fun-CosyVoice3-0.5B-2512
export TTS_COSY_DIR=/home/leo29/taigi-voice-agent/finetune/CosyVoice
export TTS_PROMPT_WAV=$TTS_COSY_DIR/asset/zero_shot_prompt.wav   # 暫用範例聲；金孫正式聲待定調
export TTS_PROMPT_TEXT='<填 zero_shot_prompt.wav 的逐字稿>'        # 07-02 實機驗證用的那句
export TTS_PRELOAD=1
/home/leo29/taigi-voice-agent/finetune/venv-cosyvoice/bin/uvicorn \
    services.tts.server:app --host 127.0.0.1 --port 8002
# 驗證：curl -s http://127.0.0.1:8002/healthz  → {"status":"ok","model_loaded":true}
# 套件若缺：先在該 venv 跑 pip install -r services/tts/requirements.txt
```

### 1.3 scheduler worker（排程：提醒／主動關懷／記憶整理；另開終端）
```bash
cd /home/leo29/kinsun
PYTHONPATH=src uv run python -m kinsun.scheduler
```

### 1.4 ngrok（把本機 :8000 對外，供 LINE webhook）
```bash
ngrok http --domain=cranial-bloomers-appealing.ngrok-free.dev 8000
```
啟動後到 **LINE Developers → Messaging API → Webhook URL** 設
`https://cranial-bloomers-appealing.ngrok-free.dev/line/webhook`，按 **Verify** 應回 Success，並確認 **Use webhook = ON**。

> ⚠️ ngrok 一開，機器人即對真實 LINE 使用者生效並產生真 Gemini 呼叫。團隊沒準備好前先別開，或測完即關。

## 4. 已知限制與缺口（實測時預期會遇到，非 bug）

- **家屬 LIFF（D 區）需先建 LINE Login channel + LIFF app** 才能測；未設前 `/liff` 靜態頁能開但登入會失敗。
- **金孫參考語音未定調**：TTS 目前是 CosyVoice 範例聲，音色非最終版。
- **mem0 + Supabase 不支援 BM25 關鍵字檢索**，長期記憶僅語意相似度；entity linking 因未裝 spaCy 降級。
- **台語**：目前 ASR/TTS 走國語鏈路；台語為後續工作。
- **排程無手動觸發 CLI**：C 區需靠改鐘點 + 重啟 worker（見 C 區說明）。
