## 1. 上次（6/24）到現在做了什麼

上次報告時我們才剛要分工、建 GitHub；這兩週把整套系統先在 LINE 上做出來、確認會動：

- **語音對話整條跑通**：長輩講話 → 語音辨識 → AI 陪聊 → 語音回覆，模型跑在自己的 DGX 主機。
- **記憶系統**：記得今天聊了什麼、長期記得長輩的事，每次回話前自動想起相關的事。
- **風險偵測**：同一句話一邊陪聊、一邊判讀健康風險，分輕重通知家人（這是我們跟別組不一樣的核心）。
- **提醒與主動關心**：吃藥提醒、回診提醒、每天主動找長輩聊。
- **家人端**：邀請建檔、用藥回診管理、健康報告。

## 2. 大轉向：從 LINE 改成自己的 App

7/7 拍板。原因：不想被 LINE 平台綁死，而且長輩的介面（大字、大按鈕、按住就說話）要自己設計才做得到。

改造分五個階段，目前走完四個：

| 階段 | 內容 | 狀態 |
| :---: | :--- | :---: |
| 1 | 底層身分改造（系統不再綁死 LINE，之後接什麼平台都不用改程式） | ✅ |
| 2 | App 帳號系統（家屬帳號密碼、長輩用綁定碼登入） | ✅ |
| 3 | App 對講機後端（講話送後端、拿語音回覆） | ✅ |
| 4 | App 介面（長輩端按住說話＋家屬端管理頁），手機實機可跑 | ✅ |
| 5 | 推播通知（要買 Apple 開發者帳號） | ⬜ 之後 |

LINE 版處置：**不刪、凍結**。現有功能照常運作，等 App 穩定後再決定去留。
