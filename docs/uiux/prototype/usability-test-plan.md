# Kinsun 長輩陪伴對話 Prototype：可用性測試計畫

> 版本：v1.1｜日期：2026-07-27｜狀態：研究包就緒，待真人場次
> 重要：本文件是研究計畫與紀錄模板，目前沒有受試者資料，也不代表研究結論。

執行時以 [主持指南](research/moderator-guide.md) 為單場腳本，以 [資料字典](research/data-dictionary.md) 紀錄；研究入口與證據門檻見 [研究包 README](research/README.md)。

## 1. 研究目標

1. 確認長輩能否在沒有教學的情況下，發現並完成語音對話。
2. 比較「短按兩次」與「按住放開」兩種手勢的理解度、操作負擔與失誤型態。
3. 確認 Listening、Thinking、Speaking 三種狀態是否能被正確辨識。
4. 確認連線失敗時，使用者能否理解問題並完成重新連線。

本輪不測試真實錄音、回答品質、登入權限、403 回復、家屬通知或 Admin trace。這些項目需待資料契約與跨職能決策完成後另行安排。

## 2. 受試者與裝置

- 建議先招募 5–6 位目標年齡層長輩，作為第一輪質性問題發現。
- 優先使用受試者平常使用的實體手機；記錄 iPhone／Android、螢幕尺寸、是否使用放大字體。
- 若受試者有手部活動、聽力或視力限制，僅記錄其自述與觀察，不做醫療推論。
- 使用同一個公開 Prototype 版本；每個任務從主持指南指定的固定連結開始，不沿用上一位受試者的畫面狀態。

## 3. 測試任務

### 任務 A：自然開始一段對話

主持人只說：「請跟阿金說，您今天早餐吃了什麼。」不提示按法。

觀察：

- 第一眼是否找到麥克風。
- 首先採用短按或按住。
- 是否在 10 秒內開始操作。
- 是否誤以為第一次短按已經送出。
- 是否需要主持人提示。

### 任務 B：使用另一種說話方式

完成任務 A 後，主持人請受試者改用尚未使用的方式：

- 短按模式：「按一下開始，說完再按一下。」
- 按住模式：「按住說話，說完再放開。」

每位受試者的任務順序交錯安排，避免所有人都被同一順序影響。

### 任務 C：辨識系統狀態

依主持指南的固定狀態連結開啟 Listening（短按與按住）、Thinking、Speaking，並逐一問：「您覺得阿金現在正在做什麼？」

只記錄受試者原話；不要先讀出畫面上的狀態名稱。

### 任務 D：從連線錯誤回復

主持人開啟固定連線錯誤連結後說：「剛才好像沒有成功，請您看看接下來會怎麼做。」

觀察是否找到「重新連線」、是否誤按「回到待機」，以及回復後是否理解已可再次說話。

## 4. 紀錄欄位

| 欄位 | 記錄方式 |
| --- | --- |
| 任務成功 | 無協助／一次中性提示後成功／直接說明後成功／未完成 |
| 首選手勢 | 短按兩次／按住放開／無法判定 |
| 首次操作時間 | 從任務說明結束到首次按下麥克風，記錄秒數 |
| 誤送或漏送 | 次數與發生時機 |
| 狀態辨識 | Listening／Thinking／Speaking 各自正確或不正確 |
| 錯誤回復 | 找到重新連線／選擇其他操作／未完成 |
| 主觀難易度 | 每任務後詢問 1–5 分，1 非常困難、5 非常容易 |
| 原話與行為 | 逐字短句、停頓、反覆點按、尋求協助 |

## 5. 主持原則

- 先觀察，再給中性提示；不要用手指指向按鈕。
- 不把 Prototype 的假回應說成真實 AI、錄音或連線結果。
- 不收集姓名、電話、健康資料或真實對話內容。
- 若受試者感到不適、挫折或想停止，立即結束該任務。
- 每完成一位受試者就另存一份觀察表，不覆寫前一份。
- repo 內只保留 `P01` 這類去識別代碼；招募、同意與聯絡資料留在核准的 repo 外位置。

## 6. 迭代門檻

下列任一情況列為 P0，先修正再繼續擴大測試：

- 無法判斷系統是否正在聽、思考或說話。
- 短按後長時間等待，誤以為內容已送出。
- 按住造成明顯操作負擔或反覆中斷。
- 連線錯誤後找不到可回復操作。

完成第一輪後，才能依真實觀察修訂 IA、元件狀態與主要手勢。不得用主持人印象或 Proto-persona 取代研究結果。

## 7. 跨場次彙整

每位受試者的 A–D 任務依資料字典附加到 `research/research-sessions.csv`，再於 repo root 執行：

```powershell
python docs/uiux/prototype/tools/summarize_usability_results.py
```

工具會先驗證欄位、代碼、一致性與明顯個資，再更新 [研究摘要](research/research-summary.md)。自動輸出只有描述性計數；洞察與改版決策仍須由研究者回看跨場次證據後補寫。
