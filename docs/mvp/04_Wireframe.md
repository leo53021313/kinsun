## 1. 長輩端（LINE 對話即介面）

### 1.1 日常對話

```
┌─ LINE 聊天室：金孫 ──────────────────────┐
│                          ┌──────────────┐ │
│                          │ 🎤 (語音 6") │ │  ← 長輩按住麥克風說話
│                          └──────────────┘ │
│ ┌──────────────┐                          │
│ │ 🔊 (語音回覆) │  ← TTS_BACKEND=dgx 時    │
│ └──────────────┘                          │
│ ┌────────────────────────────┐            │
│ │ 阿嬤早！今天有出去走走嗎？ │ ← 文字泡泡  │
│ └────────────────────────────┘  (≤40字)   │
└────────────────────────────────────────────┘
```

固定文案（出處見 [03_User_Flow](03_User_Flow.md)）：

| 情境 | 長輩看到 |
|------|---------|
| 打字（預設） | 金孫現在聽得懂語音喔，您可以按住麥克風跟我說說話。⚠ T-01 |
| 未綁定 | 金孫需要先完成綁定才能陪您聊天喔。請把家人給您的邀請碼貼到這裡，或回覆「設定」開始。 |
| ASR／管線失敗 | 金孫剛剛沒聽清楚，您可以再說一次嗎？⚠ T-37 |
| LLM 生成為空 | 金孫剛剛想了一下沒講清楚，您可以再說一次嗎？ |

## 3. 家屬端 LIFF（React SPA，`/liff`，⚠ T-43 零樣式）

頁面路由（`frontend/src/App.tsx`，BrowserRouter basename=/liff）：

### 3.1 `/` 長輩清單（EldersPage）

```
┌─ 金孫 — 家屬端 ────────────────────────────┐
│ 我的長輩                                    │
│ ┌────────────────────────────────────────┐ │
│ │ 陳阿嬤                                  │ │
│ │ [用藥] [回診] [健康報告] [邀請家屬]     │ │
│ └────────────────────────────────────────┘ │
│ 新增長輩： [稱呼________] [建立]            │
│ → 建立後顯示：長輩綁定碼（請交給長輩在      │
│    LINE 貼上，24 小時內有效）：{code}       │
│    ⚠ T-45 只顯示一次，過期無重產入口        │
└────────────────────────────────────────────┘
```

⚠ T-43：子頁面不顯示目前是哪位長輩，僅靠網址 elderId。

### 3.2 `/elders/:id/medications` 用藥（MedicationsPage）

```
│ 用藥清單                                    │
│ ・降血壓藥  早上/晚上   [編輯] [刪除]       │ ← 刪除零確認 ⚠ T-44
│ 新增： [藥名________]                       │ ← 自由文字 ⚠ T-34
│        ☐早上 ☐中午 ☐晚上 ☐睡前  [儲存]    │
```

### 3.3 `/elders/:id/appointments` 回診（AppointmentsPage）

```
│ 回診清單                                    │
│ ・2026-07-15  台大心臟科   [編輯] [刪除]    │
│ 新增： [日期 YYYY-MM-DD] [名稱____] [儲存]  │ ← 過去日期擋下 ⚠ T-46（今天判定用 UTC）
```

### 3.4 `/elders/:id/health-report` 健康報告（HealthReportPage）

```
│ 健康報告（近 30 天）                        │
│ ── 危急事件 ──                              │
│ ・07-03 14:22 · 緊急 · {reason}             │ ⚠ T-17
│ （空狀態：近 30 天無危急事件）⚠ T-47        │
│ ── 提醒紀錄 ──                              │
│ ・07-05 08:00 · 用藥 · 早上該吃藥囉：…      │
```

**共通行為**：LIFF idToken 隨每個請求送出；401 時前端**只清狀態、無重新登入提示** ⚠ E-09；
SPA 深層路徑重新整理必得 404 白頁 ⚠ E-10。

## 4. 觀測後台（`/admin`，開發團隊用）

四頁面（React 第二入口，X-Admin-Key 登入，401 清金鑰回輸入畫面）：

```
/          總覽：統計卡（輪次/危急/活躍長輩/token）＋ 24h 逐時長條圖
/messages  全域訊息流：5 秒輪詢增量、tab 隱藏暫停
/elders    長輩清單 → /elders/:id 時間軸（對話/推播/風險交錯、語音可播）
/traces/:id 單輪鏈路：webhook→ASR→LLM→TTS→回覆各段延遲
```

## 5. 設計缺口（補設計時的待辦）

1. 全站無任何 CSS／設計系統；先決定要不要引入極簡樣式（長輩不用 LIFF，受眾是家屬）⚠ T-43。
2. 高齡可及性未考慮：字級、對比、觸控目標——若未來長輩也用網頁需另議。
3. 危急警報文案需人工重寫（含長輩姓名、L2/L3 區分、免責句法務確認）⚠ T-08。
4. 老師指南建議此文件應由 Wireframe 工具（Figma）承接；現況先以本文件為準。
