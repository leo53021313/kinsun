# 🚗 台北交通 AI 助理 — 使用說明書

> 這個程式可以幫你查台北和新北市的路邊停車位、規劃交通路線，還可以用說話的方式問問題！

---

## 📁 這個專案有哪些檔案？

| 檔案名稱 | 功能說明 |
|----------|----------|
| `server.py` | 後端伺服器，負責處理所有查詢 |
| `map.html` | 地圖網頁，用瀏覽器打開 |
| `build_cache.py` | 預先建立停車格座標的工具（只需要執行一次）|
| `coords.json` | 停車格座標的資料庫（自動產生）|
| `test_token.py` | 測試 TDX 帳號是否正確 |
| `transport_agent.py` | 舊版的交通查詢程式（已整合到 server.py）|

---

## 🛒 第一步：準備需要的帳號和金鑰

在開始之前，你需要申請這三個免費帳號：

### 1. Anthropic（Claude AI）
> 這個比較特別，需要付費才能用 API，但也可以改用 Gemini（免費）

- 網址：https://console.anthropic.com
- 申請帳號後，到「Billing」加值（最少 $5 美金）
- 拿到「API Key」，長得像這樣：`sk-ant-xxxxxxxx`

### 2. Google Gemini（免費！）
- 網址：https://aistudio.google.com
- 用 Google 帳號登入
- 點左側「Get API Key」→「Create API Key」
- 拿到金鑰，長得像這樣：`AIzaxxxxxxxx`

### 3. TDX（台灣交通資料，免費！）
- 網址：https://tdx.transportdata.tw
- 右上角「註冊」，用 Email 申請
- 登入後點右上角帳號 →「金鑰管理」
- 拿到「Client ID」和「Client Secret」

---

## 📝 第二步：建立 .env 檔案

在專案資料夾裡，新建一個叫 `.env` 的檔案，裡面填入你的金鑰：

```
ANTHROPIC_API_KEY=你的Claude金鑰
GEMINI_API_KEY=你的Gemini金鑰
TDX_CLIENT_ID=你的TDX帳號
TDX_CLIENT_SECRET=你的TDX密碼
```

> ⚠️ 注意：等號兩邊不要有空格，不要加引號！

---

## 💻 第三步：安裝需要的套件

打開終端機（Terminal），輸入這些指令：

```bash
pip install flask flask-cors requests python-dotenv google-genai anthropic
```

等它安裝完，大概要等 1-2 分鐘。

---

## 🗺️ 第四步：建立停車格座標資料庫（只需要做一次！）

這個步驟會把台北市和新北市所有路邊停車格的位置都查好存起來。
**只需要做一次**，之後就不用再做了。

```bash
python build_cache.py
```

> ⏳ 這個步驟需要等大約 **60-90 分鐘**，因為要查 4000 多個地點的座標。
> 讓它跑就好，不要關掉終端機！

跑完會看到：
```
完成！共 2592 個座標存入 coords.json
```

## 🚀 第五步：啟動伺服器

```bash

```

看到這個畫面就表示成功了：
```
✅ 已載入 2592 個座標
* Running on http://127.0.0.1:5000
```

> ⚠️ 每次使用前都要先啟動 server.py，不能關掉！

> 建議用 **Chrome** 瀏覽器，因為語音功能需要 Chrome 才能用。

## 🎯 怎麼使用這個 App？

### 搜尋附近停車格
1. 在左上角的輸入框輸入地點名稱（例如：行天宮）
2. 選擇城市（台北市或新北市）
3. 按「搜尋附近停車」
4. 地圖上會出現彩色圓點：
   - 🟢 **綠色** = 有空位
   - 🔴 **紅色** = 已停滿
   - ⚫ **灰色** = 感應器無資料
5. 點擊圓點可以看到路段名稱和剩餘車位數

### 問 AI 交通問題（文字）
1. 在右側面板的輸入框輸入問題
2. 按「送出」或按 Enter
3. AI 會同時分析捷運、公車、開車三種方式並推薦最佳方案
4. 地圖會自動跳到目的地並顯示附近停車格

### 用說話問問題（語音）
1. 選擇語言（國語、English、台語）
2. 按「🎤 說話」按鈕
3. 說出你的問題，例如：「從台北車站到行天宮怎麼去？」
4. 說完後程式會自動送出問題
5. AI 回答完會自動用語音念出來

### 播放回答
- 按「🔊 播放回答」可以重新播放最新一則 AI 回答

## ❓ 常見問題

### 地圖沒有停車格圓點？
→ 確認 `server.py` 有在執行，底部按鈕會顯示「❌ 載入失敗」表示伺服器沒有啟動

### AI 沒有回答？
→ 確認 Gemini API 金鑰正確，或等一下再試（免費版有速率限制）

### 語音辨識沒有反應？
→ 確認使用 Chrome 瀏覽器，並允許麥克風權限

### 搜尋地點跑到錯誤的地方？
→ 輸入更完整的地址，例如「新北市中和區安和路」而不是「安和路」

### 停車格顯示都是灰色？
→ 感應器資料每 5 分鐘更新一次，灰色表示感應器暫時沒有資料，按「🔄 重新整理」試試

---

## 🔧 如果需要更新停車格座標

如果想要重新查詢最新的停車格位置（例如新增了新的停車路段），再執行一次：

```bash
python build_cache.py
```

然後重新啟動 `server.py`：

```bash
python server.py
```
